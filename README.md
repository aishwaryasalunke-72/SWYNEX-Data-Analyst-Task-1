## SWYNEX Data Analyst Internship - Task 1

## Data Cleaning Using Microsoft Excel

This project was completed as part of my Data Analyst Internship at SWYNEX Technologies.

### Objective

To identify and clean common data-quality issues in an online shopping sales dataset using Microsoft Excel.

### Dataset

The dataset contains 60 online shopping transaction records.

### Data Cleaning Performed

- Identified and handled missing values
- Checked and removed duplicate records
- Standardized inconsistent text values
- Standardized the Order_Date format
- Checked and handled invalid quantity values
- Validated Unit_Price values
- Validated Total_Spending
- Created a Calculated_Total column using Quantity × Unit_Price
- Verified the final cleaned dataset

### Excel Workbook

The uploaded Excel file contains:

- `Raw_Data` - Original dataset
- `Cleaned_Data` - Cleaned dataset
- `Data_Quality_Check` - Summary of data-quality checks
- `README` - Task description and cleaning steps

### Tools Used

- Microsoft Excel
- Data Cleaning
- Data Validation
- Basic Excel formulas
